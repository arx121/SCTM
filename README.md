# 🎵 SoundCloud Random Music

**Cozy terminal player that just throws random music from SoundCloud at you.**

Open the folder → double-click `start.bat`.  
No browsers, no ads, no extra windows. Pure vibe.

## ✨ How it works

Add your public SoundCloud likes or playlists. Every time the app randomly picks a track and plays it through **mpv**. Perfect when you're too lazy to choose but still want music.

## 🚀 Quick start (10 seconds)

1. Download and extract the archive  
2. Open the folder `soundcloud-random-music-windows`  
3. Run `start.bat`

On first launch it auto-installs everything.

## 📦 One-time setup

1. **Node.js** (LTS) — [download here](https://nodejs.org/)  
2. **mpv** player:
   ```powershell
   winget install -e --id shinchiro.mpv

⭐ Features
•  Random playback from likes + any public playlists
•  Unlimited sources in one session
•  Next / Previous / Pause / Repeat / Volume
•  Clean progress bar + remaining time
•  Blacklist for tracks that refuse to play
•  Listening history
•  Preloading next track (no gaps)
•  Fully portable — all settings stay inside the folder
How to add your music
Inside the app: Add source → give it a name → paste link.
Examples:
•  Likes: https://soundcloud.com/your_nick/likes
•  Playlist: https://soundcloud.com/your_nick/sets/playlist-name
🎛️ Controls
While playing, bottom bar shows actions.
Use ← → arrows + Enter.
Available: Next · Back · Pause · Repeat · Volume · Menu
💡 Pro tip.
Switch to Smart mode — it’s the smartest and most reliable, but works a bit slower.
