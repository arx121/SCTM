# 🎵 SoundCloud Random Music

**Уютный терминальный плеер, который просто кидает тебе рандомную музыку со SoundCloud.**

Открыл папку → дважды кликнул `start.bat` → и вайб пошёл.  
Никаких браузеров, рекламы и лишних окон. Только музыка.

## ✨ Фичи

- Рандом из твоих публичных лайков и плейлистов
- Сколько угодно источников в одном миксе
- Управление: следующий/предыдущий, пауза, повтор, громкость
- Красивый прогресс-бар и оставшееся время
- Чёрный список упрямых треков
- История прослушиваний
- Предзагрузка следующего (без пауз)
- Полностью портативно — всё внутри папки

## 🚀 Быстрый старт

1. Распакуй архив  
2. Открой папку `soundcloud-random-music-windows`  
3. Запусти `start.bat`

В первый раз всё само установится.
