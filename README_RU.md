# 🎵 SoundCloud Random Music
Простой терминальный плеер для Windows, который включает случайные треки из SoundCloud-лайков и публичных плейлистов.
Открыл папку, запустил `start.bat`, добавил источники — и слушаешь музыку.  
Без браузера, рекламы и лишних окон.
## Язык
- 🇬🇧 English: `README.md`
- 🇷🇺 Русский: `README_RU.md`
## 🚀 Быстрый старт
1. Скачай и распакуй архив с проектом.
2. Открой папку:
   ```txt
   soundcloud-random-music-windows

3. Запусти:

start.bat

При первом запуске программа сама установит нужные зависимости проекта.

📦 Что нужно установить

Поставить нужно только один раз.

1. Node.js LTS

Скачать Node.js LTS можно тут:

https://nodejs.org/

2. mpv player

Установить mpv можно через Windows Terminal / PowerShell:

winget install -e --id shinchiro.mpv

⭐ Возможности

* Случайное воспроизведение из SoundCloud-лайков и публичных плейлистов
* Несколько источников в одном общем миксе
* Следующий / предыдущий трек
* Пауза и повтор
* Рабочая регулировка громкости
* Прогресс-бар и оставшееся время
* История прослушивания
* Чёрный список для сломанных или недоступных треков
* Предзагрузка следующего трека для более плавного воспроизведения
* Smart mode для более надёжного поиска треков
* Портативное хранение данных: настройки, история и кэш лежат внутри папки программы

➕ Как добавить музыку

Внутри программы:

Add source → введи имя → вставь ссылку SoundCloud

Примеры:

https://soundcloud.com/your_nick/likes
https://soundcloud.com/your_nick/sets/playlist-name

Поддерживаются:

* публичные лайки
* публичные плейлисты

Приватные треки и приватные плейлисты могут не работать.

🎛️ Управление

Во время воспроизведения снизу отображается панель действий.

Управление:

← / →  выбрать действие
Enter  подтвердить

Доступные действия:

Next · Back · Pause · Repeat · Volume · Menu

🧠 Smart Mode

Smart mode — самый надёжный режим поиска треков.

Он может работать немного медленнее, зато обычно лучше справляется со страницами SoundCloud.

Рекомендуемый режим:

Smart

📁 Портативное хранение

Программа хранит данные внутри своей папки.

Там лежат:

* настройки
* история
* чёрный список
* кэш и данные предзагрузки

В AppData ничего важного не складывается.

🛠️ Решение проблем

Трек не запускается

Некоторые треки SoundCloud могут быть приватными, удалёнными, заблокированными по региону или просто недоступными.

Такие треки можно отправить в чёрный список, чтобы они не попадались снова.

Музыка накладывается после переключения

Убедись, что используешь последнюю версию программы.
Плеер должен останавливать старый процесс mpv перед запуском нового трека.

Два очень коротких трека подряд

Если два трека подряд идут меньше 30 секунд, перезапусти программу.
Обычно это значит, что SoundCloud отдал превью или неправильный трек вместо полной песни.

mpv не найден

Установи mpv:

winget install -e --id shinchiro.mpv

После установки перезапусти программу.
