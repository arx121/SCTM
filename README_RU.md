# SoundCloud Random Music

**SoundCloud Random Music** — небольшой терминальный плеер для SoundCloud.

Он запускает случайные треки из публичных лайков или плейлистов SoundCloud.
Windows-версия portable и запускается одним файлом:

```txt
start.bat
```

Главная идея простая:

```txt
открыл папку -> запустил start.bat -> играет случайная музыка из SoundCloud
```

---

## Возможности

* случайное воспроизведение из SoundCloud likes;
* случайное воспроизведение из публичных плейлистов SoundCloud;
* поддержка нескольких источников;
* следующий / предыдущий трек;
* пауза и продолжение;
* режим повтора;
* регулировка громкости;
* прогресс-бар;
* отображение оставшегося времени;
* статистика прослушивания;
* чёрный список нерабочих треков;
* история прослушанных треков;
* предзагрузка следующего трека;
* portable-настройки внутри папки проекта.

## Требования

Перед запуском нужно установить зависимости.

### 1. Node.js

Нужен для работы программы.

Скачать:

```txt
https://nodejs.org/
```

Проверка установки:

```powershell
node --version
npm --version
```

---

### 2. mpv

Нужен для воспроизведения аудио.

Установка через PowerShell:

```powershell
winget install -e --id shinchiro.mpv --source winget
```

Проверка:

```powershell
mpv --version
```

Если Windows не видит `mpv`, обычно он установлен здесь:

```txt
C:\Program Files\MPV Player\mpv.com
```

---

### 3. yt-dlp

Используется как запасной способ получения аудио из SoundCloud.

Установка через PowerShell:

```powershell
winget install -e --id yt-dlp.yt-dlp --source winget
```

Проверка:

```powershell
yt-dlp --version
```

## Запуск

1. Скачать проект.
2. Распаковать папку.
3. Открыть папку:

```txt
soundcloud-random-music-windows
```

4. Запустить:

```txt
start.bat
```

При первом запуске программа сама установит npm-зависимости.

```txt
soundcloud-random-music-windows

```

## Как добавить лайки или плейлист

Открой программу и выбери:

```txt
Add source
```

Потом введи название источника и вставь ссылку SoundCloud.

### Пример публичных лайков

```txt
https://soundcloud.com/username/likes
```

### Пример публичного плейлиста

```txt
https://soundcloud.com/username/sets/playlist-name
```

Можно добавить несколько источников.
Программа сможет случайно выбирать треки из всех включённых источников.

## Рекомендуемые настройки

Рекомендуемый метод получения аудио:

```txt
smart
```

Он пробует несколько способов получить рабочее аудио:

```txt
SoundCloud stream API
yt-dlp
yt-dlp + cookies
```

Если один способ не сработал, программа пробует следующий.

## Управление

Во время воспроизведения снизу появляется строка:

```txt
Playing 0:42/2:30 -1:48 [###-------] | [Next] Back Pause Repeat:off Volume:80% Menu | S:3
```

Управление:

```txt
Стрелки влево / вправо — выбрать действие
Enter — подтвердить выбранное действие
```

Доступные действия:

```txt
Next
Back
Pause
Repeat
Volume
Menu
```

## Полезные команды

Показать статистику:

```powershell
srm --stats
```

Показать текущие настройки:

```powershell
srm --show-config
```

Очистить прослушанные треки:

```powershell
srm --clear-played
```

Очистить чёрный список:

```powershell
srm --clear-blacklist
```

Установить метод получения аудио:

```powershell
srm --method smart
```

---

## Важно

SoundCloud не всегда отдаёт каждый трек удобным для терминала способом.

Иногда трек может работать в браузере, но не запускаться в терминале.
Если трек не удаётся воспроизвести, программа добавляет его в чёрный список и выбирает другой.
